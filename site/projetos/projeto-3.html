Portfólio de Fotografia (exemplo)

Galeria simples para um fotógrafo mostrar o trabalho, com estrutura leve e boa indexação de imagens.

HTML CSS JavaScript

Sobre o projeto

Este é um projeto de exemplo — substitua por um trabalho real assim que tiver um. A ideia é uma galeria simples, organizada por categoria (ensaios, eventos, retratos), com carregamento leve das imagens e boas descrições para cada foto.

Tecnologias e decisões

Imagens otimizadas e carregadas sob demanda, texto alternativo descritivo em cada foto e nomes de arquivo organizados — tudo isso ajuda o Google a entender e indexar as imagens do fotógrafo.

Resultado

Descreva aqui o resultado real quando tiver: quantas fotos passaram a aparecer na busca de imagens ou retorno de clientes do fotógrafo.
