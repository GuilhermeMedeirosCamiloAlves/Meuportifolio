Cardápio Digital (exemplo)

Site institucional para um restaurante fictício, feito para aparecer quando alguém pesquisa por comida na região dele.

HTML CSS JavaScript SEO local

Sobre o projeto

Este é um projeto de exemplo — substitua por um trabalho real assim que tiver um. A ideia aqui é mostrar um site de página única para um restaurante, com cardápio digital, horário de funcionamento, localização e um botão direto para pedidos pelo WhatsApp.

Tecnologias e decisões

Site estático, sem framework, priorizando carregamento rápido no celular — que é de onde vem a maior parte das buscas por comida perto de casa. Uso de dados estruturados e um título bem escrito para ajudar o site a aparecer em buscas como "restaurante perto de mim".
