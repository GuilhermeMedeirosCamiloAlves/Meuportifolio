Sobre o projeto

Este é um projeto de exemplo — substitua por um trabalho real assim que tiver um. A proposta é uma landing page de uma seção só, pensada para um prestador de serviço (autônomo ou pequena empresa) que precisa de uma página objetiva com formulário ou link direto de contato.

Tecnologias e decisões

Sem bibliotecas pesadas, poucos elementos por tela e textos escritos pensando nas palavras que o público-alvo realmente digita no Google. Estrutura de títulos organizada (H1, H2) para facilitar a indexação.

Resultado

Descreva aqui o resultado real quando tiver: tempo de carregamento, posição nas buscas ou número de contatos recebidos pela página.
